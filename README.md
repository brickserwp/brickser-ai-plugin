# Brickser AI

Build complete Bricks websites with AI. Describe your website and AI generates the entire sitemap, pages, sections, layout, style, and content for you.

## What it does

Brickser AI turns a simple prompt into a fully built Bricks website. Personalize the design, fine-tune text with AI, and publish when ready. No coding needed.

## Features

- Full website generation from a single prompt
- AI text rewrite and tuning
- Instant section shuffle
- Simple design system using CSS variables
- Expandable sitemap with unlimited pages
- Share and reuse projects across any Bricks site
- 100% native Bricks, zero dependencies
- Every change auto-saved to your project

## How it works

1. **Prompt** — Describe your website and AI plans the entire structure
2. **Personalize** — Adjust colors, fonts, images, and style. No code, no guesswork
3. **Publish** — Hit publish and your Bricks website is live

## Installation

1. Download the latest release zip from the [Releases](https://github.com/brickserwp/brickser-ai-plugin/releases) page
2. In WordPress admin, go to **Plugins > Add New > Upload Plugin**
3. Upload the zip file and activate

## Requirements

- WordPress
- [Bricks Builder](https://bricksbuilder.io/)
